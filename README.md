# The World Today — Saturday 21 November 2026

A one-page newspaper front page summing up the world's news of Saturday
21 November 2026: 35 stories across 7 regions, every story sourced with a
confidence mark. `main.py` (Python standard library only) draws the whole
page from scratch and writes `/output/entry.png`.

## Run

```
python3 main.py  # writes entry.png next to main.py
MAKEFUN_OUTPUT_DIR=out python3 main.py  # writes out/entry.png
```
